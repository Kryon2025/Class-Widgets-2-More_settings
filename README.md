# Kryon 的更多设置

Class Widgets 2 综合设置插件，融合以下功能：

- **事件倒计时动画开关**：内置"事件倒计时"组件的分钟/秒数字滚动动画可开关
- **小组件高度 / 深度**：调节组件展示高度与隐藏时保留的边缘宽度
- **堆叠组件**：把多个桌面组件叠放，按设定间隔循环滚动展示（灵动岛样式）
- **时间组件增强**：增强官方内置"时间"组件——数字滚动动画开关、显示秒/日期/星期、并排或交替布局、交替动画（迁移自"时间组件"插件）

## 使用说明

安装后在主程序「设置 → 更多设置」中统一配置动画开关与高度/深度；
堆叠组件的添加与编辑方式与原「堆叠组件」插件一致：
桌面组件编辑界面中右键堆叠组件 → 「编辑成员组件」。

## 迁移说明

本插件合并了以下三个插件，安装后请**卸载或禁用**它们，避免重复补丁与组件冲突：

- `com.event.countdown.anim`（事件倒计时动画开关）
- `com.kryon.widgets-high`（小组件自定义高度）
- `com.overlay`（堆叠组件）
- `com.time.component`（时间组件）

旧配置会在首次加载时自动迁移到 `com.kryon.more_settings`。

## 卸载

卸载插件后会自动还原主程序原始 QML（组件动画、小组件高度与堆叠编辑入口一并移除）。

## 技术说明

- 主程序补丁：`integrations.py`（幂等、可逆，备份于 `.cwplugin_backups/more_settings/`）
- 配置模型：`more_settings_config.py`（存储于 `plugins.configs.com.kryon.more_settings`）
- 堆叠后端：`overlay_backend.py`
